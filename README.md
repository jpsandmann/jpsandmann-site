# Jan-Paul Sandmann — academic website

A responsive, static website with no dependencies or tracking. All navigation and assets use relative paths, including for GitHub Pages project hosting.

## Preview

Run `python3 -m http.server 4173 --bind 127.0.0.1` in this directory and open http://127.0.0.1:4173.

## Editing

Edit index.html for the biography, research.html for publications, teaching.html for teaching, and cv.html for the CV summary. Replace assets/sandmann-cv.pdf to update the download. Shared design is in styles.css.

## Publication

No deployment workflow is enabled. Preview and approval precede any push to the public repository or hosting configuration.

The visible footer credit has been removed at the owner’s request. An inert source marker remains. No information is submitted to any directory or mailing list. Person structured data is included on each page.
